Presentación del proyecto

Este proyecto tiene como objetivo evaluar y comparar distintos modelos de aprendizaje supervisado, mostrando de forma clara su comportamiento, sus métricas y sus diferencias, con una interfaz pensada para presentación académica y análisis por parte del equipo.

Objetivo

Identificar qué modelos ofrecen mejor desempeño en tareas de regresión, apoyándose en evidencia cuantitativa, visualizaciones interactivas y ajuste automatizado de hiperparámetros.

Métodos de entrenamiento

  • Regresión Lineal
  • Random Forest
  • Gradient Boosting
  • XGBoost

Comparación de modelos

Los modelos se comparan sobre datasets reales y se ordenan de acuerdo con sus métricas de desempeño, permitiendo observar sus fortalezas y limitaciones según el tipo de problema.

Métricas utilizadas

  • Regresión: R2, MSE, RMSE y MAE.

Visualizaciones

  • Gráficas interactivas con Plotly.
  • Reducción de dimensión con PCA, t-SNE y UMAP.
  • Comparación visual de predicciones y métricas.

Datos e importación

El sistema trabaja con datasets integrados y también permite cargar un archivo CSV, revisar sus columnas, corregir el formato y reutilizarlo dentro del tablero.

¿Qué es Optuna y la Optimización Bayesiana?

Optuna es un framework de optimización de hiperparámetros. A diferencia del Grid Search tradicional (que evalúa ciegamente todas las combinaciones), utiliza Optimización Bayesiana.

Ventajas: Aprende de iteraciones pasadas para enfocar la búsqueda exclusivamente en las áreas más prometedoras de la grilla matemática, logrando una convergencia acelerada y reduciendo enormemente el tiempo de cómputo.

Desventajas: El proceso es inherentemente secuencial (difícil de paralelizar en sus algoritmos base) y agrega mayor peso al entorno productivo.

Interpretación de hiperparámetros

Selecciona un modelo y revisa el catálogo de sus hiperparámetros con explicación puntual, impacto esperado y enlace a la documentación oficial.

Intercepto (fit_intercept)

Define si el modelo estima intercepto matemático. Suele mantenerse en `True` cuando los datos no están centrados.

fit_intercept = True

Copia de matriz (copy_X)

Decide si se clona la matriz de entrada antes del ajuste. Afecta la seguridad de memoria, no el poder predictivo.

copy_X = True

Coeficientes positivos (positive)

Fuerza a que todos los coeficientes sean no negativos. Útil solo en contextos donde esa restricción matemática tiene sentido.

positive = False

Tolerancia (tol)

Tolerancia numérica del solver en ciertos caminos internos. Influye directamente en la estabilidad y convergencia.

tol = 1e-4

Paralelización (n_jobs)

Permite el uso de múltiples núcleos del procesador para acelerar el cálculo cuando es aplicable en datasets grandes.

n_jobs = None

Documentación oficial de LinearRegression

Número de árboles (n_estimators)

Cuántos árboles construye el ensamble. Más árboles suelen dar mayor estabilidad, pero suben el costo computacional.

n_estimators = 100

Profundidad máxima (max_depth)

Hasta dónde se puede ramificar cada árbol. Reduce el sesgo, pero demasiada profundidad puede subir la varianza y sobreajustar.

max_depth = None

Mínimo para dividir (min_samples_split)

Mínimo de observaciones requeridas para poder dividir un nodo interno. Ayuda a evitar reglas demasiado específicas.

min_samples_split = 2

Mínimo por hoja (min_samples_leaf)

Mínimo de observaciones al final de una hoja. Útil para suavizar el modelo en problemas ruidosos.

min_samples_leaf = 1

Variables por split (max_features)

Controla cuántas variables aleatorias se consideran al buscar la mejor división. Garantiza la diversidad de los árboles del bosque.

max_features = 'sqrt'

Muestreo (bootstrap)

Determina si cada árbol individual se entrena usando muestreo con reemplazo (bootstrap) o el dataset entero.

bootstrap = True

Documentación RandomForestRegressor

Velocidad de aprendizaje (learning_rate)

Tamaño del ajuste en cada iteración de boosting. Más chico suele ser más estable, pero tarda más y requiere más árboles.

learning_rate = 0.1

Número de etapas (n_estimators)

Cantidad de árboles débiles que se entrenarán de forma secuencial. Trabaja fuertemente en conjunto con la tasa de aprendizaje.

n_estimators = 100

Muestreo de filas (subsample)

Proporción de filas extraídas por iteración. Un valor menor a 1 reduce la varianza y acelera el cálculo (Stochastic Gradient Boosting).

subsample = 1.0

Profundidad máxima (max_depth)

Profundidad de cada árbol débil. En boosting suele mantenerse baja (ej. 3-5) para que los árboles actúen solo como pequeños correctores.

max_depth = 3

Control de hojas (min_samples)

Tanto `min_samples_split` como `min_samples_leaf` ayudan a controlar la complejidad estructural de los estimadores base.

min_samples_leaf = 1

Selección de atributos (max_features)

Restringe las variables consideradas al construir cada árbol débil, forzando a que patrones ocultos salgan a la luz.

max_features = None

Documentación GradientBoosting

Boosting Rounds (n_estimators)

Número de iteraciones o árboles a ajustar. En XGBoost se puede configurar la detención temprana si este número es alto.

n_estimators = 100

Profundidad (max_depth)

Profundidad máxima por árbol. En XGBoost, aumentar este valor hace al modelo muy complejo y propenso al sobreajuste.

max_depth = 6

Paso de aprendizaje (learning_rate)

Equivalente a 'eta'. Escala la contribución de cada árbol para prevenir el sobreajuste (shrinkage).

learning_rate = 0.3

Fracción de filas (subsample)

Razón de la muestra de instancias de entrenamiento. Previene el sobreajuste al añadir aleatoriedad antes de crecer los árboles.

subsample = 1.0

Columnas por árbol (colsample_bytree)

Fracción de variables a seleccionar aleatoriamente para cada árbol. Muy efectivo para robustecer el modelo contra ruido.

colsample_bytree = 1.0

Regularización (reg_alpha / lambda)

Términos de regularización L1 (alpha) y L2 (lambda) sobre los pesos. Ayudan a lidiar con datos de alta dimensionalidad.

reg_alpha = 0

t-SNE y UMAP con hiperparámetros ajustables

Normalización explícita

Antes de proyectar con t-SNE y UMAP, se aplica StandardScaler para estandarizar cada variable y reducir distorsiones por diferencias de escala.

t-SNE (t-distributed Stochastic Neighbor Embedding)

Descripción técnica: Convierte distancias en alta dimensión en probabilidades de vecindad y optimiza la proyección minimizando divergencia KL, priorizando estructura local.

Paper oficial: Van der Maaten & Hinton (2008)

UMAP (Uniform Manifold Approximation and Projection)

Descripción técnica: Modela una aproximación de variedad topológica y optimiza un embedding de baja dimensión que preserva estructura local y parte de la global.

Paper oficial: McInnes, Healy & Melville (2018)

Explicabilidad Avanzada (XAI) con PDP, ICE, SHAP y LIME

Analiza el comportamiento marginal e impactos globales o locales de forma independiente para cada tarea de modelado.

Guía Rápida de Interpretación Visual

Gráficos ICE (Individual Conditional Expectation): Cada línea translúcida es una fila del dataset. Muestra cómo cambiaría exactamente la predicción de esa sola persona u observación si modificamos la variable seleccionada, manteniendo el resto igual.

Gráfico PDP (Partial Dependence Plot): Es la línea gruesa que promedia todos los ICE plots. Revela la tendencia global y marginal que la variable tiene sobre las predicciones del modelo.

SHAP Summary (Barras): Promedia el valor absoluto de los impactos de SHAP. Las variables hasta arriba son las más determinantes para el modelo en términos matemáticos.

SHAP Beeswarm: Cada punto es una predicción real. El color indica si el valor de la variable era bajo o alto, y su posición en el eje X indica si empujó la predicción de forma positiva o negativa.

SHAP Dependence: Analiza una sola variable. Cruza su valor original (eje X) contra su impacto final en el modelo (eje Y), destapando patrones o "escalones" no lineales.
