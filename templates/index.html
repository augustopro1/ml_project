Proyecto de Machine Learning 2

Aplicación desarrollada por el equipo para analizar, comparar y visualizar modelos de machine learning sobre problemas de regresión y clasificación, integrando métricas, optimización de hiperparámetros, reducción de dimensión e importación flexible de datos desde CSV.

Profesor {{ professor_name }}
Datasets analizados Un dataset de regresión y un dataset de clasificación para comparar desempeño en escenarios distintos.
Enfoque del proyecto Comparación de modelos, interpretación de métricas, Optuna, PCA, t-SNE, UMAP e importación de CSV.

Presentación del proyecto

Este proyecto tiene como objetivo evaluar y comparar distintos modelos de aprendizaje supervisado, mostrando de forma clara su comportamiento, sus métricas y sus diferencias, con una interfaz pensada para presentación académica y análisis por parte del equipo.

Objetivo

Identificar qué modelos ofrecen mejor desempeño en tareas de regresión y clasificación, apoyándose en evidencia cuantitativa, visualizaciones interactivas y ajuste automatizado de hiperparámetros.

Métodos de entrenamiento

  • Regresión Lineal
  • Random Forest
  • Gradient Boosting
  • XGBoost

Comparación de modelos

Los modelos se comparan sobre datasets reales y se ordenan de acuerdo con sus métricas de desempeño, permitiendo observar sus fortalezas y limitaciones según el tipo de problema.

Métricas utilizadas

  • Regresión: R2, MSE, RMSE y MAE.
  • Clasificación: Accuracy, F1, Precision y Recall.

Visualizaciones

  • Gráficas interactivas con Plotly.
  • Reducción de dimensión con PCA, t-SNE y UMAP.
  • Comparación visual de predicciones y métricas.

Datos e importación

El sistema trabaja con datasets integrados y también permite cargar un archivo CSV, revisar sus columnas, corregir el formato y reutilizarlo dentro del tablero.

Flujo de importación

1. Cargar el archivo CSV desde el equipo.

2. Detectar columnas numéricas.

3. Elegir si el problema es regresión o clasificación.

4. Seleccionar target y features.

5. Aplicar el dataset al tablero y reentrenar.

Formato para predicción directa
